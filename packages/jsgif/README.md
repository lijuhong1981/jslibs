# @lijuhong1981/jsgif

> GIF 动图加载与播放工具，可将 GIF 动图加载并播放到 Canvas。

## 安装

```bash
npm install @lijuhong1981/jsgif
```

## 导出

- `loadGIFImage(...)` — 加载 GIF 动图
- `GIFImageLoader` — GIF 图片加载器类
- `GIFPlayer` — GIF 播放器类

依赖：`@lijuhong1981/jscheck`、`@lijuhong1981/jsdestroy`、`@lijuhong1981/jsevents`、`@lijuhong1981/jsload`、`@lijuhong1981/jstask`

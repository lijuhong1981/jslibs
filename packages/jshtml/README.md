# @lijuhong1981/jshtml

> DOM 与 Canvas 工具集（仅在浏览器环境使用），涵盖元素创建、样式注入、Canvas 绘制、图片转换等。

## 安装

```bash
npm install @lijuhong1981/jshtml
```

## 导出

- **元素/样式**：`createElementFromHTML`、`getElementById`、`appendCss`、`getCssStyleRule`
- **图片**：`createImage`、`canvasToImage`、`imageToDataURL`
- **Canvas**：`clearCanvas`、`drawTextToCanvas`、`createColorGradientCanvas`、`measureText`
- **脚本路径**：`getCurrentScriptUrl`、`getCurrentScriptFolderUrl`
- **位置**：`getPosition`

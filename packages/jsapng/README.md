# @lijuhong1981/jsapng

> APNG 动图解析与加载工具，内置 APNG 解析器（`apng-js`），可将 APNG 动图加载并播放到 Canvas。

## 安装

```bash
npm install @lijuhong1981/jsapng
```

## 导出

- `loadAPNGImage(...)` — 加载 APNG 动图
- `APNGImageLoader` — APNG 图片加载器类
- `parser` — 底层 APNG 解析器（源自 `apng-js`）

依赖：`@lijuhong1981/jsevents`、`@lijuhong1981/jsload`、`@lijuhong1981/jstask`

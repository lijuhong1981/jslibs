# @lijuhong1981/jslibs

> 聚合包，一次性汇总导出本 monorepo 中全部 `@lijuhong1981/js*` 包。

## 安装

```bash
npm install @lijuhong1981/jslibs
```

## 导出

大部分模块被**扁平导出**，`jshtml`/`jsload`/`jsmath`/`jstext`/`jsurl` 则通过**命名空间**导出：

- **扁平导出**：`jsapng`、`jscheck`、`jscolor`、`jsdestroy`、`jsevents`、`jsgif`、`jslib`、`jstask`、`jstime`、`jswindfield` 的全部导出
- **命名空间导出**：
  - `HtmlUtils` ← `jshtml`
  - `LoadUtils` ← `jsload`
  - `MathUtils` ← `jsmath`
  - `TextUtils` ← `jstext`
  - `UrlUtils` ← `jsurl`

## 包含的包

`jsapng` · `jscheck` · `jscolor` · `jsdestroy` · `jsevents` · `jsgif` · `jshtml` · `jslib` · `jsload` · `jsmath` · `jstask` · `jstext` · `jstime` · `jsurl` · `jswindfield`
